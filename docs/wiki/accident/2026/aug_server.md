# 8月長期サーバートラブル
### 概要
- 2026/08/24~2026/09/03の間、すべてのサーバーの操作が不能になった。
- その影響で、[7月鯖](../../servers/2026/jul_railway/)が長期停止、[9月鯖](../../servers/2026/sep_anarchy/)は延期となった。
- なお、なぜかトラブル解決後謎のクラッシュが多発した。

### 原因
- 電源落ち + LANケーブル抜けと思われる。(本人証言)
- 停止が長引いた理由は、あっきーのサーバーが実家に配置されており、リモートでしかアクセスできない環境下でリモート不能となり、措置を取ることができなくなったため。
